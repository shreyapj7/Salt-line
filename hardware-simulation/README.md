# SALT-LINE Hardware Simulation

This directory contains the hardware simulation assets used by SALT-LINE.

## Wokwi Simulation

Location: `hardware-simulation/wokwi/`

Files:

- `diagram.json`: Wokwi circuit and component configuration.
- `sketch.ino`: Arduino/ESP32 simulation firmware.
- `wokwi-project.txt`: Wokwi project information.

## Purpose

The simulation supports development and testing of the SALT-LINE
sensor acquisition workflow before connecting physical hardware.

## Important

Simulated readings must be identified as simulation data.

They must not be treated as real-world groundwater measurements
or operational evidence.
